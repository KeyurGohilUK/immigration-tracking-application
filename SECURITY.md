# Security Policy

## Reporting a vulnerability

Please do not disclose suspected vulnerabilities in a public issue, discussion,
pull request, or fork.

A private reporting contact will be added before the application is publicly
released. Until then, public security reports are not accepted.

Submitting a vulnerability report does not grant permission to access user
data, disrupt the service, perform destructive testing, or use, modify, or
redistribute the software.

Forks, clones, modified copies, and independently deployed versions are not
supported.
